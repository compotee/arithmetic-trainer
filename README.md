# Арифметический тренажёр

Веб-приложение для тренировки устного счёта с рейтингом игроков.

## Возможности
- Регистрация и авторизация (JWT)
- Генерация примеров на сложение и умножение
- Проверка ответов и накопление статистики
- Таблица лидеров

## Стек
- **Backend:** Python + FastAPI
- **База данных:** PostgreSQL (в планах)
- **Кэш:** Redis (в планах)
- **CI/CD:** GitHub Actions

## Быстрый старт

```bash
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
